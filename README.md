# Brackenfell

A small medieval highland village you can walk around in the browser, on a phone or a laptop.

Play it: https://brendanlymurphy.github.io/brackenfell/

## Layout

- `index.html`, `tex/` — the game as it is served (Build 4, hand-written WebGPU renderer).
- `legacy/` — source, texture tools and tests for Build 4. `node legacy/build.mjs` is the old build step.

## Credits

Surface textures are public-domain (CC0) scans from ambientCG, cgbookcase and Nobiax, some edited by CryHam for Stunt Rally 3.
See `legacy/tools/texture-provenance.json` for the file-by-file list.
